# Code of Conduct

Agent Sessions aims to be a practical, respectful open-source project.

## Expected Behavior

- Be direct and constructive.
- Assume maintainers and contributors have limited time.
- Keep discussions focused on the technical issue or project decision.
- Respect privacy when sharing logs, paths, screenshots, or hook payloads.
- Accept maintainer decisions after tradeoffs have been explained.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without consent.
- Repeatedly derailing issues or pull requests.
- Pressuring maintainers to bypass security, review, or testing expectations.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and issues that violate this code of conduct. Serious or repeated violations may result in a ban from project spaces.

Report conduct concerns privately through the repository owner profile. For security-sensitive reports, use [SECURITY.md](SECURITY.md).
